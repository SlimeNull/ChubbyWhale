## 已观察到的差异

- 所有请求指定 `size=1024x1024`，实际返回多种尺寸，甚至包含不满足原始尺寸约束的 1254×1254；不能只凭请求值报告成品尺寸。
- 多次指定 `quality=low`，响应标注 `medium`；多图蒙版编辑响应标注 `low`。脚本会记录差异，不保证网关严格执行请求参数。
- 若干透明 PNG 的 alpha 最大值为 254，主体也可能有轻微半透明；保留原始 alpha，不擅自拉伸为 255。需要按用途目视检查边缘和颜色。
- 模型列表和结果中的 model 字段均由 provider 声明；未审计服务端路由及计费实现，不能独立证明最终上游使用的底层模型。
- 当前测试覆盖 PNG、单图生成、单图编辑、多图加蒙版、真实透明背景。JPEG/WebP、4K、xhigh/max、实网 `n>1` 未做计费实测；保留为可配置 API 参数。
