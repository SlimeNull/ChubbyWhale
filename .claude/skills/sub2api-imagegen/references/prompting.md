# 提示词与编辑约束

参考 Codex imagegen 的提示词原则，但执行只使用本 skill 的独立 Images API 脚本。

用户需求已明确时只整理结构，不额外增加主体、文案、品牌或故事。信息不足但不阻塞时可补充构图、光照、用途等必要细节。

按需使用以下结构，不必凑齐每项：

```text
用途：产品素材 / 插画 / 广告 / UI 示意图
主要需求：用户要求
输入图：图1=编辑目标；图2=产品参考；图3=风格参考
主体与环境：主体、背景和必要细节
风格：摄影 / 插画 / 3D 等
构图与光照：画幅、视角、留白、光源
文字原样："必须准确渲染的文案"
允许修改：明确范围
必须保留：身份、造型、姿势、布局、文字、颜色等
避免：额外物体、裁切、水印等
```

修图时明确“只修改 X；保留 Y”，每轮重述关键保留项。参考图要说明提供内容、风格还是构图；如果是创作新图，明确参考图不要求原样保留。

透明图除设置 `background=transparent`，还应说明完整主体、透明画布、干净轮廓、是否允许阴影。不要要求“画棋盘格背景”，棋盘格应由查看器显示，而非生成到图里。

密集文字使用逐字文案、字体风格和位置要求，产出后逐字核对。迭代时每次只改一项，降低其他部分漂移。
